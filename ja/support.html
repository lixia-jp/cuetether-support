進行表、タイマー、保存したセッションの使い方。

以下は初回リリースの使い方です。App Store での配信はまだ始まっていません。

セッションの進め方

進行表はどのように使いますか？

進行表を作成し、区間を追加します。各区間に所要時間、最低時間、保護設定を指定して保存してください。セッションを開始したら、活動が終わるたびに自分で次の区間へ進みます。保存した進行表は編集、並び替え、複製して再利用できます。

予定時間を超えるとどうなりますか？

自分で次へ進むまで、現在の区間は続きます。CueTether は、固定された終了目標に対して残りの進行が収まるかを示します。時間の調整案では、これからの区間の余白に比例して短縮します。保護した区間と最低時間を守り、自分で適用するまで時間配分は変わりません。

残りの進行が収まらない場合は？

許可された範囲をすべて短縮しても収まらない時間を表示します。保護した区間や最低時間を勝手に削ることはなく、予定時刻に終わる保証もしません。残りの活動をどう扱うかは、参加者の状況を踏まえて判断してください。

一時停止すると終了目標も延びますか？

延びません。一時停止すると現在の区間の経過時間は止まりますが、終了目標は固定されたままです。停止中も終了目標までの時間は減るため、再開時には残りの配分を調整する必要が生じる場合があります。

アプリを閉じたり、画面をロックしたりできますか？

セッションの状態は端末内に保存されます。再度開くと、保存した時刻と状態から経過時間を計算して復元します。実行中のセッションは時間が進み、一時停止中のセッションは停止状態を保ちます。端末の日付と時刻は正しく設定してください。通知が届くかどうかは OS によって管理され、正確な時刻のアラームを保証するものではありません。

保存データと購入

時間の実績を書き出すには？

履歴から終了したセッションを開き、テキストまたは CSV の書き出しを選びます。システムの共有画面から保存先を指定してください。書き出す内容には進行表や区間の名前が含まれるため、共有前に内容を確認してください。書き出しは時間の実績レポートであり、アプリに読み込めるバックアップではありません。

データを削除するには？

不要な進行表やセッション履歴はアプリ内で削除できます。端末内のアプリデータをすべて消す場合は、端末からアプリを削除してください。「App を取り除く」操作ではデータが残る場合があります。書き出したコピーや端末のバックアップ内のデータは、それぞれの保存先で別途管理してください。

別の端末にもデータは表示されますか？

CueTether は端末内に保存し、端末間では同期しません。同じアプリを開き直してセッションを復元することと、端末のバックアップから復元することは別です。端末復元時にアプリデータが含まれるかは、Apple のバックアップと復元の設定によります。

購入を復元するには？

CueTether は有料アプリとして提供予定で、アプリ内課金やサブスクリプションはありません。購入した Apple Account を使い、Apple の配信・アカウントの規則に従って App Store から再ダウンロードします。アプリ内で別途復元する課金項目はありません。再ダウンロードだけでは、端末内に保存した進行表は戻りません。請求や返金の相談は、Apple の購入サポートをご利用ください。

通知

通知が届かないときは？

通知は任意のローカル通知です。アプリの通知設定と、端末の「設定」にある通知許可を確認してください。集中モード、通知の要約、消音モードなどの設定により、通知の届き方が変わる場合があります。通知を許可しなくてもタイマーは使えます。アプリから OS の制限を解除することはできません。

不具合については、アプリのバージョン、端末の機種、iOS・iPadOS のバージョン、操作手順、期待した動作を記載してください。進行表の名前は仮のものに置き換え、参加者の情報、会議内容、書き出した記録、パスワード、支払い情報は送らないでください。

公開の不具合報告も利用できます

再現できる不具合は、任意で GitHub の Issue から報告できます。投稿には GitHub アカウントが必要で、返信は Issue 上に掲載します。

GitHub の Issue は公開されます。 個人情報、参加者名、会議内容、書き出した記録、パスワード、支払い情報は投稿しないでください。画面の画像を添付する場合も、非公開の情報を先に除いてください。公開せずに相談したい場合はメールをご利用ください。
