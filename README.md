# CueTether support

Public support and privacy information for CueTether, a workshop agenda timer for iPhone and iPad.

- English: https://lixia-jp.github.io/cuetether-support/
- 日本語: https://lixia-jp.github.io/cuetether-support/ja/

The site is static HTML and CSS. To update it, edit the relevant English and Japanese pages and push to `main`. GitHub Pages publishes the repository root. Check both language versions after publishing.

Support issues are public. Use fictional examples and do not post personal information or actual session content. This repository contains website files only.
